Organ Donor Management System

A console-based Java application designed to manage organ donor information and organ donation records.

📌 About the Project

The Organ Donor Management System is a Java-based console application that helps manage information related to organ donors and organ donation records.

The project is designed to demonstrate core Java programming concepts such as Object-Oriented Programming, Collections, exception handling, and menu-driven console applications.

✨ Features

Add new donor information

View donor records

Search donor information

Manage organ donation records

Display available donor information

Menu-driven console interface

Exception handling for invalid input

🛠️ Technologies Used

Java

Object-Oriented Programming (OOP)

Java Collections

Exception Handling
